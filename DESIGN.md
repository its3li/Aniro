# Aniro — daily practice, quietly presented

Preserve the name, navy/amber palette, all prayer behavior, local Quran data,
and Arabic-first usage. This is a mobile worship companion, not a marketing site.

## Visual system
Dark navy canvas, tonal navy surfaces, amber reserved for active actions and
prayer time. The light theme uses the existing pale canvas. No mesh backgrounds,
neon glows, stock imagery, ornamental pills, or nested cards. Phosphor icons use
regular outlines, duotone active navigation and filled playback controls; a custom
bead icon follows the same geometry. Typography: self-hosted Manrope for Latin UI,
Noto Sans Arabic for Arabic UI, existing Naskh for sacred text. Quiet motion,
visible focus, reduced-motion support, logical spacing and RTL navigation.

## Information hierarchy
Home: brand/date → next prayer/time → today's prayer timeline → resume Quran →
appropriate azkar → daily wisdom. Quran: clear search, reading continuation,
flat surah index and generous verse rhythm. Azkar: recognisable category rows,
accessible buttons, persistent repetition progress. Tasbeeh: one large tactile
counter with change/reset secondary. Qibla: instrument first, status and location
below. Settings: four clear sections with anchor navigation and readable controls.

## Constraints
44px touch targets, 4.5:1 normal text contrast, no truncation of core Arabic
content, zoom enabled, narrow phone layouts tested, readable prayer times,
navigation remains available during audio playback. Preserve saved settings.

## Skill synthesis
Frontend Design, Redesign Existing Projects, Design Taste Frontend, High End
Visual Design, Minimalist UI and UI/UX Pro Max inform hierarchy, restraint,
type, surfaces and interaction. Marketing-only AIDA, heavy GSAP pinning and
random compositions do not fit daily worship flows. The installed UI/UX skill
has no search scripts/database; its documented rules are applied directly.
Image-generation tools are unavailable; the existing runnable app is the visual
target, audited using local Playwright screenshots instead of generated mockups.
