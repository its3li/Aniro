# Aniro 6.14

تحديث أنيرو بواجهة محسّنة، قراءة أوضح للقرآن، وموثوقية أفضل للأذان والقبلة.

- واجهة جديدة بنفس ألوان أنيرو، مع أسطح زجاجية هادئة وأيقونات موحّدة وحركات خفيفة.
- إصلاح المسافات وقصّ النصوص في قائمة السور وشاشات القراءة والأذكار.
- تنسيق مركزي خاص لأول صفحتين من المصحف، مع الاحتفاظ بالنص والتجويد والتلاوة.
- تحسين تشغيل الأذان، واستمرار تحدي الفجر بعد مغادرة التطبيق، وتحسين القبلة.
- ستة خيارات للويدجت بأحجام وتخطيطات أكثر مرونة.
- تقليل العمل عند بدء التشغيل وإعادة رسم شاشات القراءة، وتصغير حجم التطبيق.
- تحسين التحديث من داخل التطبيق والتحقق من ملف APK، مع مصدر بديل للتحقق من التحديثات.

**للتحديث:** افتح أنيرو ثم الإعدادات ← حول التطبيق ← التحقق من التحديثات.
وافق على إذن تثبيت التحديثات إذا طلبه أندرويد. إذا لم يظهر التحديث، حمّل
aniro-v6.14.apk من هذه الصفحة وافتحه لتحديث التطبيق. لا تحتاج إلى حذف
التطبيق؛ التحديث الرسمي يحتفظ بالإعدادات وموضع القراءة والعدادات المحفوظة.

Aniro 6.14 refreshes the interface, improves Quran reading, and strengthens prayer
and compass behavior.

- Refined navy/amber interface with soft glass surfaces, a consistent icon family,
  and focused animations with reduced-motion support.
- Fixed Quran list spacing, reader toolbar gaps, and clipped Arabic labels.
- Centered live-text composition for Mushaf pages 1 and 2; later pages retain the
  standard reading flow. Tajweed and verse actions remain available.
- Improved azan scheduling/playback, persistent Fajr challenge behavior, and native
  Qibla sensing.
- Six widget options with more flexible sizes and layouts.
- Reduced startup work and reader rerenders; removed a redundant search asset.
- More reliable update checks, permission return handling, and APK verification.

**Upgrade:** Open Aniro → Settings → About → Check for updates. Allow Aniro to
install updates if Android requests it, then confirm installation. If the prompt
does not appear, download aniro-v6.14.apk below and open it. Install over the
existing official app to keep your saved data. Very old versions may open this
download page instead of downloading inside the app.

Android 7.0 or newer. Package: com.aniro.app; version code: 20.
Signed with the same official certificate as versions 6.8–6.13.
An older build signed with another certificate cannot be updated in place by
Android. The published 6.4 APK uses an older certificate. Do not uninstall it
without first preserving any data you need.

Validation: signed Android release build, release/backend checks, and 32 desktop
and mobile browser checks passed, including update discovery and install-permission
return handling. Real azan/challenge and Qibla behavior were tested on the connected
phone during preparation.
